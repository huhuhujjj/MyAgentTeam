🎯 核心理念

普通聊天 = 一个模型对你单聊，一次性，无记忆；MyAgentTeam = 一个由你设计的 AI 团队彼此讨论，记得过去任务，知道你是谁，把你的问题打磨清楚后再给你答案。

普通 LLM 聊天
  • 单模型对你单聊
  • 每次任务从零开始
  • 不知道你是谁
  • 厂商锁定 + 服务器中转
  • 失败常常沉默
→
MyAgentTeam
  • 多 Agent 协作辩论
  • 5 路长程记忆按需注入
  • 项目上下文 + 自学画像
  • 6 厂商可混 + 浏览器直连
  • 7 状态码翻译 + 可操作建议

📦 3 个内置场景 —— 每个生产稳定，每个用最合适的编排模式

F+11 产品聚焦 · F+12 起底替换写作：从 6 → 3 极致聚焦，每个场景都做到生产可用。开箱即用，零配置。输入框写一句话，系统自动识别 → 启动。需要写作 / 分析 / 学习等其他场景？用「🛠️ 自定义团队」装配（5 编排模式 + 11 预设，包括完整的写作 4 工序）。

🧠 长程会话记忆 NEW

普通聊天每次任务都是金鱼脑。MyAgentTeam 通过 5 个独立记忆源给 Agent 持续上下文，每条都可独立开关 + 设置 token 预算上限：

📌
项目上下文
你手填的 500 字长期背景（"我是 SaaS 创业者，偏好简洁"），注入每个任务的每个 Agent
软上限 800 token
🧬
用户画像（自学）
任务结束后 LLM 自动摘要"关于你的新事实"（最多 20 条 FIFO），30 天自动过期
软上限 400 token
🔗
引用过往任务
启动新任务时可选"基于之前 React vs Vue 那次决策继续"，结果摘要进入新任务上下文
软上限 600 token
📂
知识库（RAG）
上传 .txt / .md 文档 → 浏览器内分块 → 任务启动时按关键词召回 top-3 相关 chunk
软上限 800 token
🤖
Agent 个体记忆
每个内置 Agent 累积自己跑过的任务记忆，下次启动时回顾"我之前为该用户做过什么"
软上限 300 token · 默认关
📊 Token 预算可视化
启动任务时弹层展示"记忆消耗"明细：每源已用多少 token，总共 +多少费用。超总预算自动按优先级裁剪低优先级源。
🧹 自动 Hygiene
启动时自动跑：30 天过期清理 / Jaccard ≥ 0.7 去重 / 一正一反冲突检测。设置面板可手动「🧹 立即清理」。
🛡 你完全掌控
5 个独立开关 + "不记忆此任务"勾选 + 导出/导入 JSON + 一键清空全部记忆 + 可选 PBKDF2+AES-GCM 加密整个记忆库。

⏯ 任务延续：刷新页面或意外断网，未完成的任务会自动恢复 —— 首页顶部出现「⏯ 继续未完成的任务」横幅，一键回到原任务。

🔧 Agent 工具调用 NEW

普通模型 API 调用没有联网能力，"分析最新数据"只能凭训练截止日期前的知识 → 容易瞎说。工具调用让 Agent 在回答前**主动查实**：

🌐
web_search
联网搜索（Tavily 全球可用，免费 1000/月）。Agent 拿到真实 URL + 摘要 + 时间
用户带 Tavily Key
📄
web_fetch
把搜索结果 URL 进去读全文 markdown（Jina Reader 免 Key）。深读源文档
免 Key
🕐
date_now
告知当前日期 / 时区。让 Agent 写"截至 2026 年 X 月..."而非"截至我所知"
纯本地
🧮
js_execute
Web Worker 沙箱内执行 JS：算数 / 排序 / 统计 / 数据处理。防模型算错
纯本地
🔄 自动循环
Agent 自主决定调用哪个工具、调几次，最多 5 轮。无需用户介入。
🛡 多层防御
单工具超时 30s + 结果自动截断 8000 字符 + 沙箱执行 + 5 轮硬上限，防失控
⚙ 精细控制
自定义团队每个 Agent 独立"启用工具"勾选，内置 6 场景一个全局开关

解决了集体幻觉问题：多 Agent 辩论时，没有工具的话每个 Agent 都引用训练数据 → 即便互相质证，也可能"集体说错"。开启工具后，每个 Agent 看到的是同一份真实搜索结果，证据基于事实，辩论才有意义。

🛠 Agent 工具调用 F+ NEW

普通 LLM 通过 API 调用时没有联网能力 —— 即使多 Agent 互相辩论，也只是基于 2024 训练数据的"集体幻觉"。MyAgentTeam 给 Agent 配了 3 个工具，让事实有真实出处：

🌐
web_search
通过 Tavily API 联网搜索实时信息，返回 5-10 条 web 结果含真实 URL、标题、摘要
需 Tavily Key（免费 1000 次/月）
📄
web_fetch
深读 URL —— 通过 Jina Reader 抓取完整页面，返回 Markdown（前 8000 字）
免 Key（Jina Reader 公开服务）
🕐
date_now
获取当前日期、时间、时区。让 Agent 写"2026 年..."而不是"截至我所知"
免 Key（纯本地 JS）

F+ 强制工具的 2 个场景

不是所有场景都需要联网。F+ 设计原则：事实依赖高的场景默认强制工具，事实无关的场景保持纯发散。

⚖️ 决策 A B C 取证 + 协调裁决前都强制 web_search。无 Tavily Key 启动时显示集体幻觉警告。
📝 写作 撰稿强制搜真实案例数据；校对强制 web_search + web_fetch 验证每条引用。

不强制工具的场景

  • 规划：走全局开关（设置面板「🛠️ 内置场景允许 Agent 调用工具」），不强制
  • 自定义团队：每个 Agent 卡片可独立勾选"🛠 启用工具"

💡 工具执行循环：每个启用工具的 Agent 最多 5 次 tool_call 循环（决策/分析 Phase 1 Agent prompt 强制至少 4 次 web_search 充分调研 · F+5）。Agent 自主决定调哪个工具、调几次、何时停 —— 这是"workflow + 节点内 Agent"混合架构的"Agent"部分。短 ctx 模型（如豆包 lite 32K）累积超 ctx*0.6 阈值时自动折叠老 tool result，保留最新 1 个完整（F+6）。

📁 项目空间 F+11 NEW

解决多主题混用时跨任务记忆污染的问题。每个项目是独立命名空间，🧠 用户画像 / 📌 项目上下文 / 🤖 Agent 记忆 完全隔离 —— 周一在"前端选型"项目学到的事实，绝不会污染周三的"住房决策"项目。

🔀
独立命名空间
每个项目独立的 📌 项目上下文 / 👤 用户画像 / 🧠 Agent 记忆。历史任务按 projectId 过滤显示。
共享：⚙ 设置 / 📂 知识库 / 🛠 自定义团队
⚡
顶栏一键切换
右上角项目 chip → dropdown 切换 / 新建 / 管理。任务运行中自动禁用切换避免上下文错乱。
最小操作成本
🛡
零迁移成本
旧版本数据首次加载自动迁移到「默认」项目，幂等可重入。"默认"项目不允许删除，避免误操作。
向后兼容

典型用法：技术决策 + 个人事务 + 工作项目 A/B/C 分开管理，AI 团队的"用户认知"在每个项目里独立成长。

🧠 工程哲学 · 4 个决策原则 F+18.1 NEW

这个项目不只是"做功能"，更是"把每个决策的思考过程留下痕迹"。以下 4 条原则贯穿 F+1 到 F+18.1：

🔄
自我修正闭环
F+17 模型失败自动记忆 → 成功调用自动 clear → 30 天自动过期。试错成本由系统消化，不该让用户做计算机能做的判断。同理：F+18 的 starred 排序、自定义 model ID 持久化都遵循这个原则
F+17 · F+18
📜
服务器原话 > 本地推断
F+14.3 之前：handleApiError 自己猜原因 "请求被拒绝" / "可能是审核"。F+14.3 之后：把 vendor 的 error.message 直接显示。"友好提示"和"原始信息"应该并存，不是二选一。1 次抽象救了所有未来 bug 定位
F+14.3
↩️
撤回不丢脸
F+4 降 TOOL_LOOP_MAX 优化 → F+5 撤回（用户要充分调研）。F+14 honest 接受 CORS 限制 → F+14.1 撤回，做 hybrid 透明代理。计划好"可以撤回"反而能更激进地尝试。两次撤回都让架构更好
F+5 · F+14.1
🛡
多 vendor = 自我免疫系统
F+16 修了一个 OpenAI/Claude/Qwen 都宽容掩盖了几个月的 bug —— Phase 2 history.content=[]。豆包严格按协议校验直接 400 暴露。如果只支持单厂商，这个 bug 会潜伏到很久以后才在客户端升级时炸出来
F+16

觉得 3 个内置场景不够？点首屏「🛠️ 自定义团队」chip 进入团队构建器，完全按你的需求装配（写作 / 分析 / 学习 / 创意 / 反思 / 头脑风暴 等场景预设都内置）：

  • 1-4 个 Agent：独立命名 + 自定义身份描述（System Prompt）+ 独立选模型 + 独立选颜色
  • 5 种编排模式可选：顺序 / Pipeline 流水线 / Reflection 反思 / Hub-Spoke 中心辐射 / Multi-phase 多阶段 —— 详见下一节
  • 团队库：把当前团队命名保存，建多套预案（"周报专用队"、"竞品分析队"、"决策辩论队"），下次下拉一键切换
  • 模板库：身份描述可保存为可复用的模板（自动放进"我的模板"），跨团队套用
  • 11 套精选预设一键载入：⚖️ 三方对抗辩论 / 🏛 三方辩论 / 📊 多视角分析 / ✍️ 写作流水线 / 🪞 反思打磨 / 🎙 多专家问诊 / 🎓 苏格拉底学习 / 🔬 四厂商对照 / 🎨 创意三人组 / 💰 经济型团队 / 🧠 深度推理团队

🔐 隐私与安全

这套产品的底层假设是：你的数据是你的，不在我的服务器上，也不在任何中间人手里。

🛡 零中间服务器 浏览器直连 6 家厂商 API，Key 加密存储于本地（首次填入时引导设置主密码，可跳过），Vercel 只托管静态文件不经手任何 API 调用。
🔒 AES-GCM 加密（首次填 Key 引导开启） NEW 首次保存真实 API Key 时引导设置主密码（可跳过）→ PBKDF2 10 万次迭代派生 → AES-GCM 256 位加密 API Key + 项目上下文 + 记忆库，以 ENC1: 密文落盘 localStorage。会话级密钥缓存 sessionStorage（关浏览器即清），新会话需主密码解锁。
💉 Prompt 注入防护 用户输入用 <user_input> 标签包裹，prompt 明确要求 Agent 忽略其中的指令性内容。输入长度上限 2000 字。
🧼 XSS 防护 所有 Markdown 输出经 DOMPurify 清洗，禁用 script / iframe / on* 危险标签和属性。
💰 成本硬熔断 场景 1-5 单任务 $1 / 场景 6 + 自定义 $2，超过即终止并保留已生成内容。每次任务前预估对话框告知预算。
👁 Key 永远不进日志 UI / 日志中 Key 全部以 sk-…xxxx mask 显示，避免误传。

💬 FAQ · 5 个最常被问的问题

Q1 · 我的 API Key 真的不会上传到任何服务器吗？
核心承诺：5 家厂商（OpenAI/Anthropic/Qwen/DeepSeek/Gemini）的 Key 完全本地存储 + 浏览器直连，Vercel 只托管静态文件不经手任何 API 调用。

唯一例外：豆包 ARK 不开 CORS（厂商决定），生产环境走 /api/proxy/ark Vercel Edge Function 透明代理 —— 但代理纯 pass-through 80 行，不存 Key、不读 body、不 log。F+14.1 详见 CHANGELOG.md。

进阶：可选 AES-GCM 256 加密本地存储（PBKDF2 10 万次迭代派生密钥），见隐私 section。
Q2 · 跑一个任务大概要花多少钱？怎么避免烧爆
典型成本（用旗舰模型）：决策场景 $0.05-$0.30 · 起底 $0.15-$0.50 · 规划 $0.02-$0.10。用 mini 系列再砍一半。

防爆 3 层：① 任务前弹层"成本预估"用户确认 · ② 单任务硬熔断（decision/dossier $5 上限）· ③ 实时面板每 Agent token + cost 累积可见。

省钱组合：Phase 1 取证用 mini 模型（gpt-4o-mini / claude-haiku / qwen-turbo）· Phase 3 裁决用旗舰（claude-sonnet-4.5 / gpt-5）。场景 chip ⚙ 可为每 Agent 单独选模型。
Q3 · 为什么选浏览器直连而不是后端代理？
3 个理由：
① 0 凭证存储承诺真实可信 —— 后端代理意味着 Key 要经过服务器，必然涉及"存不存"问题。浏览器直连从源头消除疑问。
② 0 服务器成本 —— 你跑多少任务花多少厂商的钱，我不在中间烧任何服务器。
③ 可审计 —— F12 网络面板能看到每次请求直接发到 api.openai.com 等厂商域名，没有中间人。

代价：CORS 限制（豆包 ARK 必须走代理，已用 Edge Function 透明代理解决）。
Q4 · 我喜欢的 model ID 列表里没有，或某个 model ID 过期了怎么办？
F+17.1 已支持：每个 model 下拉每个厂商 optgroup 末尾有 ✏️ 填自定义 model ID... 选项。点击 → 弹 prompt → 输入任意 ID → 持久化复用。

典型场景：① 厂商发了新版（如 doubao-seed-1-6-pro-250615）应用还没更新 → 自己填 · ② Volcengine 自建 endpoint ep-xxxxxxxx → 自己填（自动识别为豆包） · ③ 旧 model ID 已下线 → F+17 会给该 model 加 ⚠ 标 + tooltip 显示"上次失败 HTTP 404"。

自我修正：成功调用一次的 model 自动从"失败列表"清除 ⚠ 标。
Q5 · 离线能用吗？数据备份怎么搞？
离线：UI 完全可加载 + 介绍页/设置/历史查看 100% 工作，但跑 LLM 任务必须联网（厂商 API 在云上）。Tavily 搜索 / Jina Reader 也需联网。

备份导出：① 单任务 📥 导出 .md（含原文/Agent/讨论/结果）· ② 整库 设置 → 导出全部 JSON（含 config / history / memory / projects / 自定义团队）· ③ 加密用户可导出加密包。

跨设备：把导出的 JSON 在新设备 设置 → 导入 即可。没有云同步（守住 0 后端原则）。

🚀 怎么开始用

最快路径 · 3 步

  1. 点右上角齿轮 ⚙ → 填入任一厂商的 API Key（不填则全程模拟，能体验完整交互但不调真模型）
  2. 回到首页，输入框写一句话描述你的任务，或直接点 3 个内置场景中的一个（规划 / 决策 / 起底）
  3. 看 Agent 实时流式讨论 → 拿结果。任务结束页可"重新生成"或"查看完整讨论"或"导出 Markdown"

事实可信路径 · 4 步（推荐用于决策 / 分析 / 写作）

  1. 同上 Step 1，先填厂商 Key
  2. 额外填 Tavily Search Key（在 tavily.com 用 Google 30 秒注册，免费 1000 次/月）
  3. 启动「决策 / 分析 / 写作」任何一个 → 系统提示 "🔧 F+ 强制启用 web_search"
  4. 看 Agent 自主搜索 → 每条数据带真实 URL → 拿到事实可追溯的结果

进阶路径 · 跨厂商混合

  • 给内置场景换模型：场景 chip 上的齿轮 ⚙ → 为每个 Agent 单独选模型 → ✨ 标记会出现
  • 自定义你的 AI 团队：首屏点「🛠️ 自定义团队」chip → 团队构建器 → 选编排模式 → 配 Agent 身份 + 选模型 → 启动
  • 直接载预设：进团队构建器后点「📚 浏览内置预设」→ 11 套精选范式（辩论 / 写作流水线 / 反思打磨 / 问诊 / 四厂商对照等）一键载入
  • 保存你的团队：在团队构建器顶部给团队取个名字 → 「💾 保存」入团队库，下次直接切换
  • 任务中实时介入：底部输入框补充信息（"重点放在用户体验" / "别太长"等），最多 3 次，5 种模式下都生效
